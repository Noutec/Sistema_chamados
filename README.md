# Central de chamados

## Objetivo do projeto

Este projeto foi criado para ajudar na organização e no acompanhamento de chamados internos de suporte técnico. A ideia é permitir que os usuários registrem problemas, acompanhem o andamento e vejam rapidamente o status de cada solicitação.

## O que o sistema faz

- abre novos chamados;
- mostra todos os chamados em uma lista;
- separa por status: ativos, em andamento e resolvidos;
- permite buscar e filtrar informações;
- exibe os detalhes de cada chamado;
- edita ou exclui registros;
- salva os dados no navegador.

## Como usar
1. Clique em “Abrir chamado”.
2. Preencha as informações do problema.
3. Salve o chamado.
4. Na página inicial, você poderá visualizar, buscar, filtrar e acompanhar o status.
5. Ao clicar em "Detalhes" ou "Editar", você acessa mais informações e pode alterar o chamado.
